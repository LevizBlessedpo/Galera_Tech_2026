# Galera Tech 2026

Este repositório foi criado com o objetivo de registrar e publicar os projetos desenvolvidos durante o programa **Galera Tech 2026**.

Ao longo dessa jornada, serão documentados os exercícios práticos, projetos de sala de aula e os conceitos fundamentais aprendidos em desenvolvimento web.

---

## 📚 Conteúdos e Conceitos Praticados

- **HTML5:** Estruturação de páginas, formulários interativos e criação/manipulação de tabelas.
- **CSS3:** Estilização, layout responsivo e formatação visual.
- **Bootstrap:** Uso do sistema de grid (Grid System) e componentes para interfaces responsivas.
- **PHP:** Processamento de formulários, identificação do navegador do usuário e gerenciamento de cookies (criação e leitura).
